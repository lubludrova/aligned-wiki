# Self-Enhancing Video Data Management System for Compositional Events with Large Language Models

VOCAL-UDF extends a video-query vocabulary by generating reusable programs or small visual models for missing predicates.

## Problem and contribution

A compositional video query fails when an existing system lacks a required concept. VOCAL-UDF identifies missing predicates and creates user-defined functions instead of repeatedly asking a large model to evaluate every object pair (§§1–4).

## Approach

Natural-language query → parser and missing-UDF proposer → candidate generation and selection → executable query over stored video relations → matching videos (Figure 2).

Program-based candidates operate on available object attributes or pixels. Distilled-model candidates learn a concept from labels generated by a stronger vision-language model. Syntax checks reject unexecutable programs, while active user labeling helps select semantically appropriate candidates. DuckDB executes the resulting query, and the storage manager retains source videos, relational data and reusable UDFs (§§4–5).

Generation and inference have different costs: learning a predicate once can avoid repeated expensive calls across later queries. The evaluated setting is a prepared video database, not autonomous continuous inspection.

## Evidence and limits

Experiments use CLEVRER, CityFlow-NL and Charades, varying missing predicates and generation strategies (§6). Difficult relations and noisy visual labels remain limitations. The system assumes sufficiently explicit queries and domain-relevant primitives.

A fallback dummy UDF always returns True, effectively omitting a predicate when other candidates perform poorly (§4.4.2). This can be useful for retrieval but must not silently relax a compliance condition. State-changing UDFs that jointly inspect multiple timestamps are unsupported, although sequences of frame-level states can approximate some changes (§8). Generated explanations and executable code do not independently certify visual correctness.
